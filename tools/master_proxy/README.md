# CoD2 web masterlist proxy

Browser Join Game cannot use UDP `getservers` / `getinfo`. This tiny HTTP proxy
fetches [api.cod.pm](https://api.cod.pm) server-side and exposes JSON at
`/play/api/masterlist/cod2/1.3` (same origin as the COEP game page).

## Project server directory, Quick Play and sessions

With `COD2_SERVERS_FILE=/etc/cod2/servers.json` (format: `servers.example.json`,
or generated by `tools/run_server_fleet.py`) the proxy lists only the project's
own servers and serves `GET /servers`, `POST /matchmake`, `POST /join`,
`POST /matchmake/release`. With `COD2_SESSION_SECRET` (same value for the relay)
it also serves `POST /session` and requires sessions; `COD2_BANS_FILE` lists
banned player ids. Without `COD2_SERVERS_FILE` it keeps proxying the public
list (old behaviour). See `HANDOFF.md`.

## VPS setup

```bash
sudo mkdir -p /opt/cod2-master-proxy
# server.py imports directory.py and sessions.py from the same folder.
sudo cp tools/master_proxy/server.py tools/master_proxy/directory.py tools/master_proxy/sessions.py /opt/cod2-master-proxy/
sudo cp tools/master_proxy/cod2-master-proxy.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now cod2-master-proxy

# Add location /play/api/ from nginx-play-api.conf.snippet (or tools/nginx-cod2-web.conf)
sudo nginx -t && sudo systemctl reload nginx
```

Smoke test:

```bash
curl -sS http://127.0.0.1:20711/health
curl -sS http://127.0.0.1:20711/masterlist/cod2/1.3 | head -c 200
curl -sS https://HOST/play/api/masterlist/cod2/1.3 | head -c 200
```

## Local dev

Preferred (static web + master + WS relay, same-origin `/play/api/`):

```bash
python tools/serve_web_local.py
# open http://127.0.0.1:8080/cod2.html
```

Standalone:

```bash
python3 tools/master_proxy/server.py
# point Module.COD2_MASTER_URL at http://127.0.0.1:20711/masterlist/cod2/1.3
# (local page without COEP can call it directly; production uses /play/api/)
```
